Чтобы выполнить запуск приложения которое уже было установленно в миникуб, сначала запускаем миникуб
`minikube start`
Затем запускаем веб интерфейс миникуба, чтобы было удобно им управлять
`minikube dashboard`
Чтобы уметь обращаться к сервисам в кластере с локальной машины необходимо запустить тунелирование
`minikube tunnel`
Запускаем postgres для локальных клиентов
`kubectl port-forward --namespace otus-infra svc/otus-pstgr-postgresql 5432:5432`
