Чтобы установить postgres в minikube необходимо выпольнить:
1) подготовку миникуба
   minikube delete
   minikube start --cni=bridge
   minikube addons enable storage-provisioner
   minikube addons enable default-storageclass
2) выполнить команду установки миникуба в namespace infra
   helm install otus-pstgr oci://registry-1.docker.io/bitnamicharts/postgresql -n otus-infra --create-namespace
3) затем выполнить проброс порта на localhost
kubectl port-forward --namespace otus-infra svc/otus-pstgr-postgresql 5432:5432
4) password можно получить из секрета командой
   kubectl get secret otus-pstgr-postgresql -o jsonpath="{.data.postgres-password}" -n otus-infra | base64 -d
и декодировать его из base64

Чтобы выполнить деплой user-service в minikube необходимо выполнить:
1)  helm install userservice .\user-service-chart\ -n otus-msa --create-namespace
если необходимо удалить чарт helm uninstall userservice -n otus-msa --create-namespace
если необходимо обновить чарт helm upgrade --install userservice ./user-service-chart -n otus-msa
    (helm plugin install https://github.com/databus23/helm-diff -> helm diff upgrade userservice ./user-service-chart)
